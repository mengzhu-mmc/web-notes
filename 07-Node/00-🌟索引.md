# 07-Node · Node.js

> 运行时机制、服务端工程、生产运维、性能诊断。

## 学习定位

- **模块职责**：沉淀 Node.js 相关的核心概念、实践经验和面试复习材料。
- **整理原则**：主干文档沉淀稳定知识；课程笔记统一归档到 `课程笔记/`，不与主干知识笔记混排。
- **索引约定**：本文是中文主索引；`README.md` 仅作为兼容入口。

## 推荐学习路径

Node 的知识分两层：**语言运行时**（事件循环、模块、Stream）和**服务工程**（架构、进程、运维、数据、安全）。
只补前者会停在「会写脚本」，面试一问生产细节就穿。建议按下面顺序推进：

1. **建立地图** → [Node 能力地图与适用场景边界](./01-总览/Node能力地图与适用场景边界.md)、[Node 生产项目全景图](./01-总览/Node生产项目全景图.md)
2. **打牢机制** → 下方「运行时机制」四篇（面试基本盘）
3. **补齐生产** → [05-生产运维](./05-生产运维/README.md)（**最短板，优先级最高**）
4. **落到自己代码** → 用「生产项目全景图」里的就绪度清单改造 [Todo 全栈项目](../11-项目实战/Todo全栈项目/README.md)
