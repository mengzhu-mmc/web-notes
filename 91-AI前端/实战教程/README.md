## 公共环境约定（所有教程通用）

- **Node ≥ 20**（需要原生 `fetch`、`AbortController`、ESM 顶层 await）
- **React 18+ / Vite + TypeScript** 起前端，**Express** 起后端
- 任何 **OpenAI 兼容接口**都可以：DeepSeek、通义千问、智谱、OpenAI 官方……换 `baseURL` + `model` 即可，教程代码不绑定某一家
- 密钥一律放服务端 `.env`（`.gitignore` 掉），**永远不出现在前端代码里**

```bash
# 各教程统一的 .env 约定
OPENAI_BASE_URL=https://api.deepseek.com   # 换成你在用的兼容接口
OPENAI_API_KEY=sk-xxxx                     # 对应平台的 key
MODEL=deepseek-chat                        # 对应平台的模型名
```
