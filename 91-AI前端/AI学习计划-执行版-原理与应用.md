# AI 学习计划 · 执行版（A+B：原理 + 应用）

> 设计思路：双线并进。**A 线（原理）**用微软《面向初学者的生成式 AI》21 课打底，建立系统认知；**B 线（应用）**用前端工程项目把原理落到代码。两条线每周交替推进，周末做整合。
> 节奏：每天 60-90 分钟（A 线 30-45 分钟 + B 线 30-45 分钟）；共 6 周，可按实际进度伸缩。
> 主教材：微软《面向初学者的生成式 AI》中文版（21 课，含 Learn 课与 Build 课）[generative-ai-for-beginners / translations / zh-CN](https://github.com/microsoft/generative-ai-for-beginners/tree/main/translations/zh-CN)。

## 一、双线总览

| 线             | 关注点                                           | 主资源                                | 产出形态                  |
| -------------- | ------------------------------------------------ | ------------------------------------- | ------------------------- |
| **A 线：原理** | 概念、模型、提示工程、RAG、Agent、安全、生命周期 | 微软 21 课中文版                      | 每课一页笔记 + 关键词卡片 |
| **B 线：应用** | 前端工程落地：流式 UI、工具调用、生成式 UI       | 本仓库 `AI前端工程师指南.md` + AI SDK | 可运行 Demo + 复盘笔记    |

> A 线对应课程清单（微软 21 课，节选）：01 GenAI 与 LLM 简介、04 提示工程基础、05 高级提示、07 构建聊天应用、08 搜索与向量数据库、11 函数调用、13 安全、15 RAG 与向量数据库、17 AI 代理[generative-ai-for-beginners / translations / zh-CN](https://github.com/microsoft/generative-ai-for-beginners/tree/main/translations/zh-CN)。

## 二、6 周执行表

### 第 1 周：基础认知 + 安全调用

- **A 线（原理）**
  - 微软课 01「生成式 AI 与大型语言模型简介」：理解 GenAI 与 LLM 工作原理。
  - 微软课 02「探索与比较不同的 LLM」：建立选型直觉。
- **B 线（应用）**
  - 用后端代理完成一次安全模型调用，重点：鉴权、限流、日志脱敏、密钥不进前端。
  - 实现最小流式聊天 UI，区分 loading / streaming / done / error。
- **整合**：写一页《模型擅长/不擅长清单》，并跑通一个流式对话 Demo。

### 第 2 周：提示工程

- **A 线**：微软课 04「提示工程基础」+ 课 05「高级提示」，实践 system / few-shot / chain-of-thought。
- **B 线**：把提示模板抽成可复用配置；做一个「prompt 实验台」，对比同一任务不同提示的输出差异。
- **整合**：沉淀一份《前端高频提示模板》（代码审查、文案改写、JSON 抽取）。

### 第 3 周：文本/聊天应用与结构化输出

- **A 线**：微软课 06「构建文本生成应用」+ 课 07「构建聊天应用」。
- **B 线**：给聊天加结构化输出（schema 约束 + JSON 解析失败重试）；引入消息持久化，区分 UI 消息与模型消息。
- **整合**：做一个「AI 面试题解释器」：输入题目 → 输出知识点、常见追问、示例代码、风险提示。

### 第 4 周：搜索 / 向量 / RAG

- **A 线**：微软课 08「构建搜索和向量数据库应用」+ 课 15「RAG 与向量数据库」。
- **B 线**：把本仓库 Markdown 做成最小 RAG 原型（只读，不写文件）：切片 → embedding → 检索 → 带引用回答。
- **整合**：实现引用卡片 + 「无召回则返回不确定」+ prompt injection 防护提示。

### 第 5 周：函数调用 / 工具 / Agent

- **A 线**：微软课 11「函数调用」+ 课 17「AI 代理」。
- **B 线**：用 AI SDK 的 agent-loop 做「多步检索 → 汇总」小 Agent；设计一个只读工具和一个需审批的写工具。
- **整合**：跑通 1 个本地 stdio MCP server，理解 Tools / Resources / Prompts 三原语（对照 `09-工程化/MCP协议原理与协作流程.md`）。

### 第 6 周：安全 / UX / 生命周期 + 收尾项目

- **A 线**：微软课 03「负责任地使用 GenAI」+ 课 12「AI 应用 UX」+ 课 13「安全」+ 课 14「生命周期」。
- **B 线**：给前几周的项目补齐：工具调用审批、长任务取消/重试、来源可追溯、敏感信息过滤。
- **整合**：把一个项目打磨成可展示作品 + 一页架构图 + 一页安全清单。

## 五、执行原则

1. **A 先于 B**：每个主题先过原理课，再写代码，避免「会跑 Demo 但讲不清原理」。
2. **每课一产出**：原理课产出笔记，应用课产出代码，杜绝「只看不练」。
3. **安全贯穿**：每周复盘一次密钥、权限、工具审批、引用来源、日志脱敏。
4. **每周回流**：把稳定结论回流到 `AI前端工程师指南.md`，碎片不堆积。
5. **跟风向调整**：结合 `AI大佬前沿讯息.md` 的范式判断，动态调整选学模块的投入。
