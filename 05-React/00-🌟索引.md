## 现代 React 主线学习路径

1. **并发渲染基础**：先读 [React Fiber 架构与虚拟 DOM](./React_Fiber与Concurrent_Mode详解.md)，理解 render 可中断、commit 不可中断、紧急/非紧急更新分层。
2. **React 19 主干 API**：再读 [React 18/19 新特性与 Server Components 主线指南](./React18-19新特性与Server_Components.md)，重点掌握 Actions、`useActionState`、`useOptimistic`、`use` 与 RSC 边界。
3. **React 19.2 工程心智**：继续读 [React 19.2 实践心智模型](./React19.2实践心智模型.md)，把 `<Activity />`、`useEffectEvent`、PPR 和 SSR Resume 放进性能链路里理解。
4. **性能与 Compiler**：最后读 [React Compiler 自动记忆化心智模型](./React_Compiler自动记忆化.md) 与 [React 性能优化实战](./React性能优化指南.md)，避免继续把所有优化都写成手动 `memo/useMemo/useCallback`。

> 后续新增内容默认优先补齐 React 主线与 TypeScript 示例；Vue 相关内容仅做必要勘误、索引和格式维护。
