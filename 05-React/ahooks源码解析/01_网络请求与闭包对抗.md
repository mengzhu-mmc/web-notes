# ahooks 源码级学习指南 (上)：网络请求与闭包对抗

> 学习 ahooks 的源码，本质上是在学习如何**对抗 React 闭包陷阱**、**如何优雅地管理生命周期**以及**如何提取可复用的 DOM/BOM 操作逻辑**。ahooks 的底层哲学是：**重度依赖 `useRef` 来保持数据的最新状态且不触发重复渲染**。

---

## 一、核心网络与架构体系

### 1. `useRequest`

- **作用：** 管理异步数据请求的终极 Hook。
- **使用场景：** 所有的 API 请求（轮询、防抖、错误重试、SWR 缓存、分页、加载更多等）。
- **实现原理：** 采用**洋葱模型/插件化架构**。底层维护了一个 `Fetch` 实例来管理 `loading`、`data`、`error` 等核心状态。
- **简易代码实现（核心思想提取）：**

```tsx
function useRequest(service, options = {}) {
  const [data, setData] = useState();
  const [loading, setLoading] = useState(false);

  // 1. 使用 useLatest 缓存配置和请求函数，避免闭包陷阱
  const serviceRef = useRef(service);
  serviceRef.current = service;

  const run = useCallback(async (...args) => {
    setLoading(true);
    try {
      const res = await serviceRef.current(...args);
      setData(res);
      return res;
    } catch (error) {
      console.error(error);
    } finally {
      setLoading(false);
    }
  }, []);

  useEffect(() => {
    if (!options.manual) {
      run();
    }
  }, [options.manual, run]);

  return { data, loading, run };
}
```

- **拓展：** React 19 虽然推出了 `use()` 和 Server Actions，但客户端复杂的竞态处理，依然需要 `useRequest` 这样的调度器。React 19 的 `use()` 用法演示：

```tsx
// React 19 的 Suspense + use() 组合
import { use, Suspense } from "react";

const fetchUser = fetch("/api/user").then((res) => res.json());

function UserProfile() {
  // 直接在渲染中读取 Promise，无需 useEffect 和 useState
  const user = use(fetchUser);
  return <div>{user.name}</div>;
}
```

## 二、对抗闭包陷阱与性能优化

### 2. `useLatest`

- **作用：** 永远返回 state 或 props 的最新值。ahooks 内部几乎一半以上的 hook 都依赖它。
- **核心源码实现：**

```tsx
import { useRef } from "react";

function useLatest<T>(value: T) {
  const ref = useRef(value);
  ref.current = value; // 每次渲染都更新盒子里的值
  return ref;
}
```

### 3. `useMemoizedFn`

- **作用：** 持久化 function 的引用，同时内部一定能拿到最新的 state/props。
- **使用场景：** 传递给子组件的事件回调，替代 `useCallback`。
- **核心源码实现：**

```tsx
function useMemoizedFn<T extends noop>(fn: T) {
  // 1. 用 useRef 缓存最新的传入函数（防闭包）
  const fnRef = useRef<T>(fn);
  fnRef.current = useMemo(() => fn, [fn]);

  // 2. 用另一个 useRef 缓存永远不变的包装函数（防重渲染）
  const memoizedFn = useRef<PickFunction<T>>();
  if (!memoizedFn.current) {
    memoizedFn.current = function (this, ...args) {
      // 3. 真正调用时，去第一个 ref 里面找最新的函数执行
      return fnRef.current.apply(this, args);
    };
  }

  return memoizedFn.current as T;
}
```

### 4. `useCreation`

- **作用：** 替代 `useMemo` 或 `useRef` 的强化版，确保实例真正只被创建一次。
- **核心源码实现：**

```tsx
function depsAreSame(oldDeps: any[], deps: any[]): boolean {
  if (oldDeps === deps) return true;
  for (let i = 0; i < oldDeps.length; i++) {
    if (!Object.is(oldDeps[i], deps[i])) return false;
  }
  return true;
}

function useCreation<T>(factory: () => T, deps: any[]) {
  const { current } = useRef({
    deps,
    obj: undefined as undefined | T,
    initialized: false,
  });

  // 如果没有初始化，或者依赖变了，就重新执行 factory
  if (current.initialized === false || !depsAreSame(current.deps, deps)) {
    current.deps = deps;
    current.obj = factory();
    current.initialized = true;
  }

  return current.obj as T;
}
```

### 5. `useDebounce` / `useDebounceFn`

- **核心源码思想 (以 useDebounce 为例)：**

```tsx
import debounce from "lodash/debounce";

function useDebounce<T>(value: T, options?: DebounceOptions) {
  const [debounced, setDebounced] = useState(value);

  // 利用 useDebounceFn 包装 setState
  const { run } = useDebounceFn(() => {
    setDebounced(value);
  }, options);

  // 监听 value 变化，触发防抖函数
  useEffect(() => {
    run();
  }, [value]);

  return debounced;
}
```

- **拓展：React 18 `useDeferredValue` 宏观防抖演示：**

```tsx
import { useState, useDeferredValue } from "react";

function SearchPage() {
  const [query, setQuery] = useState("");
  // React 会在浏览器空闲时再处理 deferredQuery
  const deferredQuery = useDeferredValue(query);

  return (
    <>
      <input value={query} onChange={(e) => setQuery(e.target.value)} />
      <ExpensiveList query={deferredQuery} />
    </>
  );
}
```
