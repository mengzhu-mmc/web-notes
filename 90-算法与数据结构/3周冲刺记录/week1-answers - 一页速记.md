# week1-answers - 一页速记

> 来源：[[week1-answers]]。本页用于高频复习，完整细节回到原文。

## 必背主线

- 算法复习不适合长文阅读，应该按题型模板和错题原因复盘
- Week1 优先沉淀数组、字符串、哈希、双指针、滑动窗口、栈队列
- 每题记录：题型识别、核心思路、复杂度、易错点、相似题
- 面试表达要先说暴力解，再说优化思路和复杂度变化
- 高频题需要反复默写模板，而不是只看答案

## 面试表达公式

1. **先澄清问题**：明确范围、约束和目标指标。
2. **给出主方案**：说明核心流程和关键设计。
3. **补充工程细节**：讲性能、异常、监控、兼容性。
4. **说明取舍**：解释为什么这样做，以及替代方案的成本。
