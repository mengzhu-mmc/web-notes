**DP 核心要点**：

- 完全背包（可重复）→ 正序遍历
- 0/1 背包（不可重复）→ 倒序遍历
- 求最值 → `dp[i] = min/max(选, 不选)`
- 求方案数 → `dp[i] += dp[i-xxx]`

**回溯核心要点**：

- 去重必须先排序
- `i > start && arr[i] === arr[i-1]`：同层去重（组合/子集类）
- `i > 0 && arr[i] === arr[i-1] && !used[i-1]`：全排列去重
- start 参数控制起始位置，避免重复组合
