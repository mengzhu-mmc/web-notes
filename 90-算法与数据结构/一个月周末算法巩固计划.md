# 一个月周末算法巩固计划

> 目标：在已完成 3 周冲刺的基础上，把“看得懂答案”升级为“能独立识别题型、迁移模板、稳定写出代码”。
>
> 节奏：只安排周六、周日，共 4 个周末 8 天。每次建议 3～4 小时；如果时间不足，优先完成“复盘 + 盲写 + 错题归因”。

## 总体原则

### 训练目标

1. **题型识别**：看到题目先判断是双指针、滑动窗口、哈希、栈、二分、树、回溯、DP、图、贪心还是综合题。
2. **模板迁移**：不是背某一道题，而是能把同一类题的共同框架迁移到新题。
3. **边界稳定**：重点解决空数组、单元素、重复元素、越界、初始化、遍历顺序、状态定义等问题。
4. **表达清楚**：每题复盘时都要能说清楚：暴力解、优化点、复杂度、为什么这样写。

### 每天固定流程

1. **15 分钟**：回顾对应专题的一页速记或标准答案。
2. **30 分钟**：盲写模板，不看答案。
3. **90～120 分钟**：做 3～5 道题，优先中等题。
4. **30 分钟**：错题复盘，记录错因。
5. **15 分钟**：口述总结，模拟面试表达。

### 每题复盘模板

```md
## 题目：xxx

- 题型：
- 第一反应：
- 暴力解：
- 优化思路：
- 关键不变量 / 状态定义：
- 复杂度：
- 本次错误：
- 下次识别信号：
- 相似题：
```

## 第 1 周：数组、字符串、哈希、双指针、滑动窗口

### 周六：基础题型识别与模板迁移

**目标**：把 Week1 中最基础的题型重新打牢，重点训练“看到题知道用什么”。

#### 训练专题

- 数组原地修改
- 哈希计数
- 双指针
- 前缀和
- 二分查找基础

#### 必练能力

- 读写指针如何定义
- 哈希表存什么
- 指针什么时候移动
- 二分边界如何统一
- 前缀和如何转化区间问题

#### 推荐题型

1. 原地删除 / 移动元素
2. 两数之和 / 三数之和
3. 有序数组双指针
4. 子数组和为 K
5. 搜索插入位置 / 第一个大于等于目标的位置

### 周日：滑动窗口与字符串专项

**目标**：解决滑动窗口不够灵活的问题，重点训练“扩张、收缩、更新答案”的节奏。

#### 训练专题

- 固定窗口
- 可变窗口
- 字符串计数
- 最长 / 最短连续区间

#### 必练能力

- 窗口内维护什么状态
- 什么时候收缩左边界
- 答案在扩张时更新还是收缩后更新

#### 推荐题型

1. 无重复字符的最长子串
2. 最小覆盖子串
3. 找到字符串中所有字母异位词
4. 长度最小的子数组
5. 替换后的最长重复字符

3. 全排列

### 周日：动态规划专项

**目标**：解决 DP 不灵活的问题，强制按“五步法”表达。

#### 训练专题

- 一维 DP
- 二维 DP
- 背包问题
- 子序列问题
- 状态压缩

#### DP 五步法

1. 定义 `dp` 含义
2. 写状态转移
3. 定义初始化
4. 确定遍历顺序
5. 分析复杂度与空间优化

#### 推荐题型

1. 爬楼梯
2. 零钱兑换
3. 01 背包变体
4. 最长递增子序列
5. 最长公共子序列

## 错题归因分类

每道错题至少归到一个原因：

- [ ] 没识别出题型
- [ ] 想到题型但模板不熟
- [ ] 边界条件错误
- [ ] 状态定义错误
- [ ] 遍历顺序错误
- [ ] 数据结构选错
- [ ] 复杂度不满足要求
- [ ] 代码实现细节错误
- [ ] 能写代码但讲不清楚

## 最终验收标准

一个月结束后，至少达到：

1. 能独立写出 10 个核心模板：双指针、滑动窗口、前缀和、单调栈、链表反转、树递归、BFS、回溯、DP、并查集。
2. 看到中等题，3 分钟内能判断 1～2 个候选题型。
3. 每道题都能说清楚暴力解、优化点和复杂度。
4. 错题不再只记录答案，而是记录“下次识别信号”。
5. 综合限时题正确率稳定提升。
