# 一个月周末算法巩固计划

> 目标：在已完成 3 周冲刺的基础上，把“看得懂答案”升级为“能独立识别题型、迁移模板、稳定写出代码”。
>
> 节奏：只安排周六、周日，共 4 个周末 8 天。每次建议 3～4 小时；如果时间不足，优先完成“复盘 + 盲写 + 错题归因”。

## 总体原则

### 训练目标

1. **题型识别**：看到题目先判断是双指针、滑动窗口、哈希、栈、二分、树、回溯、DP、图、贪心还是综合题。
2. **模板迁移**：不是背某一道题，而是能把同一类题的共同框架迁移到新题。
3. **边界稳定**：重点解决空数组、单元素、重复元素、越界、初始化、遍历顺序、状态定义等问题。
4. **表达清楚**：每题复盘时都要能说清楚：暴力解、优化点、复杂度、为什么这样写。

### 每天固定流程

1. **15 分钟**：回顾对应专题的一页速记或标准答案。
2. **30 分钟**：盲写模板，不看答案。
3. **90～120 分钟**：做 3～5 道题，优先中等题。
4. **30 分钟**：错题复盘，记录错因。
5. **15 分钟**：口述总结，模拟面试表达。

### 每题复盘模板

```md
## 题目：xxx

- 题型：
- 第一反应：
- 暴力解：
- 优化思路：
- 关键不变量 / 状态定义：
- 复杂度：
- 本次错误：
- 下次识别信号：
- 相似题：
```

### “答案校验”使用方式

每个训练日的 **必练能力** 都补充了“判断标准 / 参考答案”。做题前先尝试自己回答，再对照判断标准校验：

- 如果能独立说出判断标准，说明这类题的思维入口基本稳定。
- 如果只能看懂但说不出来，说明还停留在“答案记忆”，需要补一次模板盲写。
- 如果判断标准和自己想法不一致，优先记录到错题本的“下次识别信号”。

## 第 1 周：数组、字符串、哈希、双指针、滑动窗口

### 周六：基础题型识别与模板迁移

**目标**：把 Week1 中最基础的题型重新打牢，重点训练“看到题知道用什么”。

#### 训练专题

- 数组原地修改
- 哈希计数
- 双指针
- 前缀和
- 二分查找基础

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| 读写指针如何定义 | **读指针**负责遍历原数组，**写指针**表示下一个应该写入的位置。适用于删除元素、移动零、去重等“保留部分元素”的题。 |
| 哈希表存什么 | 哈希表通常存 **出现次数、元素到下标的映射、前缀和出现次数、访问状态**。如果题目问“是否出现 / 出现几次 / 找配对”，优先考虑哈希。 |
| 指针什么时候移动 | 双指针移动取决于当前状态和目标状态的差距。有序数组中常见规则是：和太小移动左指针，和太大移动右指针。 |
| 二分边界如何统一 | 先固定区间定义。闭区间用 `left <= right`，左闭右开用 `left < right`。不要混用边界写法。 |
| 前缀和如何转化区间问题 | 区间和 `sum(i..j)` 可以转为 `prefix[j + 1] - prefix[i]`。如果要找和为 `k` 的子数组，可以查历史前缀和 `prefix - k`。 |

1. [移除元素](https://leetcode.cn/problems/remove-element/)

4. [三数之和](https://leetcode.cn/problems/3sum/)
5. [和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)
6. [搜索插入位置](https://leetcode.cn/problems/search-insert-position/)
7. [在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

### 周日：滑动窗口与字符串专项

**目标**：解决滑动窗口不够灵活的问题，重点训练“扩张、收缩、更新答案”的节奏。

#### 训练专题

- 固定窗口
- 可变窗口
- 字符串计数
- 最长 / 最短连续区间

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| 窗口内维护什么状态 | 通常维护字符计数、元素频次、窗口和、满足条件的字符种类数、最大/最小值等。状态必须能随左右指针移动增量更新。 |
| 什么时候收缩左边界 | 当窗口不再满足约束，或已经满足条件但要尝试最优答案时收缩。最长题通常“不合法就收缩”，最短题通常“合法时尽量收缩”。 |
| 答案何时更新 | 最长类一般在窗口合法后更新最大值；最短类一般在窗口满足条件时更新最小值，然后继续收缩。 |
| 如何避免全量比较 | 用 `valid`、`matched`、`formed` 等计数变量记录满足要求的字符种类数，避免每次比较整个 map。 |
| 固定窗口和可变窗口区别 | 固定窗口长度不变，右进左出；可变窗口长度由条件决定，右指针扩张，左指针按约束收缩。 |

#### 推荐题型

2. [最小覆盖子串](https://leetcode.cn/problems/minimum-window-substring/)
3. [找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)
4. [长度最小的子数组](https://leetcode.cn/problems/minimum-size-subarray-sum/)
5. [替换后的最长重复字符](https://leetcode.cn/problems/longest-repeating-character-replacement/)
6. [字符串的排列](https://leetcode.cn/problems/permutation-in-string/)

#### 当天产出与验收答案

| 当天产出 | 合格标准 |
|---|---|
| 写出滑动窗口通用模板 | 模板必须包含：右指针扩张、更新窗口状态、while 收缩、更新答案。 |
| 总结固定窗口和可变窗口区别 | 能用一句话说明：固定窗口看长度，可变窗口看约束。 |

**目标**：强化指针和数据结构操作稳定性，减少实现细节错误。

#### 训练专题

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| 单调栈维护递增还是递减 | 找“下一个更大元素”通常维护单调递减栈；找“下一个更小元素”通常维护单调递增栈。栈里存下标更方便计算距离。 |

## 第 3 周：回溯、动态规划

### 周六：回溯专项

**目标**：把排列、组合、子集、棋盘类题目统一到同一套框架下。

#### 训练专题

- 子集
- 组合
- 排列
- 去重
- 剪枝

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| path 表示什么 | `path` 表示当前已经做出的选择，也就是递归树上从根到当前节点的路径。 |
| startIndex 是否需要 | 组合 / 子集通常需要 `startIndex` 防止重复选择前面的元素；排列通常不需要 startIndex，而是用 `used` 控制是否使用过。 |
| used 数组是否需要 | 排列题通常需要 `used`，因为每层都可以从所有元素中选择未使用的数。组合题一般用 startIndex 控制选择范围。 |
| 如何处理重复元素 | 先排序，再在同一树层跳过重复选择。常见条件是 `i > startIndex && nums[i] == nums[i - 1]`。 |
| 剪枝条件是否安全 | 剪枝必须不漏解。常见剪枝是剩余元素不足、当前和已超过目标、当前选择已不可能优于答案。 |

#### 推荐题型

1. [子集](https://leetcode.cn/problems/subsets/)

3. [组合](https://leetcode.cn/problems/combinations/)
4. [全排列](https://leetcode.cn/problems/permutations/)
5. [全排列 II](https://leetcode.cn/problems/permutations-ii/)
6. [括号生成](https://leetcode.cn/problems/generate-parentheses/)
7. [N 皇后](https://leetcode.cn/problems/n-queens/)

|---|---|
| 写出回溯通用模板 | 模板必须包含：结束条件、for 选择、做选择、递归、撤销选择。 |

### 周日：动态规划专项

**目标**：解决 DP 不灵活的问题，强制按“五步法”表达。

#### 训练专题

- 一维 DP
- 二维 DP
- 背包问题
- 子序列问题
- 状态压缩

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| 如何定义 dp | `dp` 必须有明确语义，例如 `dp[i]` 表示到第 i 个位置的最优解，或 `dp[i][j]` 表示前 i 个物品容量 j 的最大价值。 |
| 如何写状态转移 | 状态转移来自“最后一步选择”。例如选或不选、匹配或不匹配、从前一个状态转移。 |
| 初始化怎么定 | 初始化要匹配 dp 语义。比如计数类通常有 `dp[0] = 1`，最值类要考虑无效状态初始值。 |
| 遍历顺序怎么确定 | 遍历顺序取决于状态依赖。如果 `dp[i]` 依赖前面状态，就从前往后；01 背包一维压缩容量倒序，完全背包容量正序。 |
| 如何做空间优化 | 只有当当前状态只依赖上一层或前几个状态时才能压缩。压缩后必须保证不会覆盖仍需要的旧状态。 |

#### 推荐题型

1. [爬楼梯](https://leetcode.cn/problems/climbing-stairs/)
2. [零钱兑换](https://leetcode.cn/problems/coin-change/)
3. [分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)
4. [最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)
5. [最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)
6. [打家劫舍](https://leetcode.cn/problems/house-robber/)
7. [不同路径](https://leetcode.cn/problems/unique-paths/)

#### 当天产出与验收答案

| 当天产出 | 合格标准 |
|---|---|
| 每题写完整 DP 五步法 | 不能只写代码，必须写 dp 定义、转移、初始化、遍历、复杂度。 |
| 总结 01 背包和完全背包遍历顺序区别 | 必须明确：01 背包倒序，完全背包正序。 |
| 记录 3 个状态定义错误 | 每个错误都要说明原定义哪里不闭合、为什么无法转移。 |

## 第 4 周：图、贪心、综合模拟、面试压测

### 周六：图与贪心

**目标**：训练非线性结构和证明能力。

#### 训练专题

- DFS / BFS 建图
- visited 状态
- 拓扑排序
- 并查集
- 贪心证明
- 区间问题

#### 必练能力与参考答案

| 必练能力 | 判断标准 / 参考答案 |
|---|---|
| 图如何建模 | 网格题通常把每个格子看成节点，四方向是边；依赖关系题用有向图；连通分量题用无向图或并查集。 |
| visited 何时标记 | BFS 通常入队时标记，避免重复入队；DFS 通常进入节点时标记，避免重复递归。 |
| BFS 和 DFS 怎么选 | BFS 适合最短步数、层序扩散；DFS 适合连通性、路径搜索、回溯式遍历。 |
| 拓扑排序如何判断环 | 用入度队列处理入度为 0 的点。如果最终处理节点数少于总节点数，说明存在环。 |
| 贪心为什么正确 | 不能只说每次取最优，要用交换论证、排序规则或反证说明局部最优不会破坏全局最优。 |

2. [课程表](https://leetcode.cn/problems/course-schedule/)
3. [省份数量](https://leetcode.cn/problems/number-of-provinces/)
