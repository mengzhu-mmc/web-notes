# 03-三、核心进阶 - 标准答案索引

## 回答结构

## 高频标准答案

### Q1：事件循环怎么答？

JS 主线程执行同步代码，异步任务完成后进入任务队列。每轮宏任务执行完会清空当前微任务队列，然后再进入渲染和下一轮宏任务。Promise.then、queueMicrotask 属于微任务，setTimeout、事件回调、网络回调通常属于宏任务。

**关键词**：宏任务、微任务、Promise、渲染时机

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q2：闭包是什么？

闭包是函数和其词法环境的组合。内部函数即使在外部函数执行结束后，仍然可以访问外部作用域变量。它常用于数据私有化、函数工厂、缓存，但也可能因为长期持有引用导致内存无法释放。

**关键词**：词法作用域、私有变量、缓存、内存泄漏

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q3：深拷贝怎么答？

浅拷贝只复制第一层引用，深拷贝会递归复制嵌套对象。工程上优先考虑 structuredClone 或成熟库；手写时要处理数组、对象、Date、RegExp、Map/Set、循环引用和原型等边界。

**关键词**：structuredClone、循环引用、Map、Set、原型

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q4：this 指向怎么判断？

this 的指向取决于调用方式，而不是定义位置。默认调用指向全局或 undefined，隐式调用指向调用对象，显式调用由 call/apply/bind 指定，new 调用指向新对象，箭头函数没有自己的 this，会捕获外层 this。

**关键词**：默认绑定、隐式绑定、显式绑定、new、箭头函数

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q5：原型链怎么答？

每个对象都有内部原型，构造函数有 prototype。访问属性时如果对象自身没有，会沿着原型链向上查找，直到 null。原型链用于属性共享和继承，但过深会影响查找，也容易出现共享引用类型属性的坑。

**关键词**：prototype、__proto__、constructor、继承

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q6：Promise 的状态和链式调用怎么理解？

Promise 有 pending、fulfilled、rejected 三种状态，状态一旦 settled 就不可再变。then/catch/finally 会返回新的 Promise，因此可以链式调用；回调返回普通值会传给下一个 then，返回 Promise 会等待其状态。

**关键词**：pending、fulfilled、rejected、thenable、链式调用

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q7：async/await 和 Promise 的关系？

async 函数本质返回 Promise，await 会暂停当前 async 函数后续执行，并等待右侧 Promise settled。await 后面的代码可以理解为放入微任务继续执行。它改善可读性，但错误处理仍要用 try/catch 或 catch。

**关键词**：async、await、Promise、try/catch、微任务

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q8：防抖和节流区别？

防抖是在连续触发停止一段时间后只执行一次，适合搜索输入、窗口 resize 后处理。节流是在一段时间内最多执行一次，适合滚动监听、拖拽和高频上报。选择时看业务需要最后一次结果还是固定频率响应。

**关键词**：debounce、throttle、resize、scroll

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q9：垃圾回收怎么答？

JS 引擎会自动回收不可达对象。常见算法包括标记清除和分代回收。前端内存泄漏常来自全局引用、未清理定时器/事件监听、闭包长期持有 DOM、大对象缓存不释放等。

**关键词**：可达性、标记清除、分代回收、内存泄漏

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q10：ES Module 和 CommonJS 区别？

CommonJS 是运行时加载，导出的是值的拷贝或对象引用，主要用于 Node 历史生态。ES Module 是编译期静态结构，支持静态分析、Tree Shaking 和 live binding，更适合现代前端构建。

**关键词**：CJS、ESM、静态分析、Tree Shaking、live binding

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q11：Map 和 Object 怎么选？

Object 更适合固定结构的数据模型，键主要是字符串或 Symbol。Map 适合动态增删键值、键类型不限、需要稳定迭代顺序和频繁读写的场景。WeakMap 适合用对象做弱引用键，避免阻止垃圾回收。

**关键词**：Map、Object、WeakMap、键类型、迭代

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q12：如何判断数组、对象和类型？

基础类型可用 typeof，但 null 会返回 object。数组用 Array.isArray，对象可结合 Object.prototype.toString，实例关系可用 instanceof。跨 iframe 或复杂场景下，toString 判断更稳。

**关键词**：typeof、Array.isArray、instanceof、toString

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。
