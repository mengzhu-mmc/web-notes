## 回答结构

- **结论**：先直接回答核心问题。
- **原理**：解释关键机制，不只背定义。
- **实践**：结合项目落地、指标或复杂度说明。
- **追问**：主动暴露可深入的方向。

## 高频标准答案

### Q1：如何设计一个前端权限系统？

先区分路由权限、菜单权限、按钮权限和数据权限。前端通过登录态、用户角色/权限点、路由守卫和组件级权限控制展示，后端必须做最终鉴权。工程上要考虑权限缓存、动态路由、刷新恢复、灰度和无权限兜底页。

**关键词**：路由权限、按钮权限、数据权限、后端鉴权

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q2：如何设计大文件上传？

核心是分片、并发上传、断点续传、秒传和失败重试。前端计算文件 hash，按固定大小切片并发上传，服务端记录已上传分片，全部完成后合并。还要考虑暂停恢复、进度展示、限流、校验和异常兜底。

**关键词**：分片、hash、断点续传、秒传、并发

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q3：如何设计一个通用表单系统？

可以从 Schema 驱动、字段组件映射、校验规则、联动逻辑、布局、权限和提交适配展开。重点是把业务差异配置化，把复杂联动和异步校验封装为可维护的扩展点。

**关键词**：Schema、校验、联动、字段组件

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q4：如何设计一个通用弹窗系统？

通用弹窗要解决调用方式、层级管理、生命周期、数据传递、关闭确认和无障碍。可以提供命令式 API 和声明式组件两种方式，内部维护弹窗队列、z-index、滚动锁定和统一样式。

**关键词**：弹窗、命令式 API、队列、z-index

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q5：如何设计前端埋点系统？

埋点系统要支持曝光、点击、停留、转化和错误等事件。设计上包括事件规范、自动采集、手动埋点、队列缓存、批量上报、失败重试、采样和隐私脱敏。关键是保证数据准确和业务可分析。

**关键词**：埋点、曝光、批量上报、采样、脱敏

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q6：如何设计低代码页面搭建？

低代码核心是物料体系、Schema 协议、画布编辑、属性面板、渲染引擎和发布链路。难点在组件扩展、版本兼容、表达式/联动、安全沙箱、权限和回滚。

**关键词**：低代码、物料、Schema、渲染引擎

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q7：如何设计一个复杂表格？

复杂表格要考虑列配置、排序筛选、分页、固定列、虚拟滚动、批量操作、权限、单元格编辑和导出。大数据量场景下需要服务端分页/筛选，并控制单元格渲染成本。

**关键词**：表格、虚拟滚动、服务端分页、列配置

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q8：如何设计前端错误监控？

错误监控包括 JS 运行时错误、Promise 未捕获错误、资源加载失败、接口错误和白屏。SDK 要采集上下文、路由、用户环境、 sourcemap 还原、去重聚合，并提供告警和看板。

**关键词**：错误监控、sourcemap、白屏、告警

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q9：如何设计搜索联想？

搜索联想要处理输入防抖、请求取消、缓存、空态、加载态、错误态和键盘操作。接口返回要防止乱序覆盖，可以用 AbortController 或请求序号保证只展示最新结果。

**关键词**：搜索、防抖、AbortController、缓存

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q10：如何设计主题切换？

主题切换可以基于 CSS Variables 维护设计 token，运行时切换根节点 class 或变量。要考虑首屏防闪、系统主题、用户偏好持久化、图片/图表主题和第三方组件适配。

**关键词**：主题、CSS Variables、Token、防闪

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q11：如何设计前端国际化？

国际化包括文案资源、语言检测、运行时切换、日期货币格式、复数规则、RTL、懒加载语言包和缺失文案兜底。工程上要提供提取、校验和翻译协作流程。

**关键词**：i18n、语言包、Intl、RTL、兜底

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。

### Q12：如何设计离线缓存能力？

离线能力通常基于 Service Worker、Cache Storage 和本地存储。静态资源可预缓存，接口数据可按策略缓存。要处理版本更新、缓存淘汰、离线提示、数据冲突和安全边界。

**关键词**：Service Worker、Cache Storage、离线、版本更新

**追问方向**：原理细节、边界条件、项目落地、性能/安全/复杂度影响。
