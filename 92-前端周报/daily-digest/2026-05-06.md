> JS 2026 新增 `using` 和 `await using` 关键字，自动管理资源释放（如文件句柄、数据库连接），告别手动 `try...finally`

**💻 浏览器支持**：Chrome 134+ / Edge 134+ / Firefox 141+ / Safari ❌ / Opera 119+

**📝 代码示例**
```javascript

  constructor(name) { this.name = name; }
  [Symbol.dispose]() { console.log(`Resource ${this.name} disposed.`); }
}

  using resource = new MyResource("Database Connection");
  console.log(`Using: ${resource.name}`);
} // 自动调用 Symbol.dispose

// `await using` — 异步清理

  await using fileHandle = await openFile("data.txt");
  // 工作代码
} // 文件自动关闭
```

### ⭐ `Array.fromAsync()` — 异步迭代器转数组（来源：W3Schools/ECMAScript 2026）

**💻 浏览器支持**：Chrome 121+ / Edge 121+ / Firefox 115+ / Safari 16.4+ / Opera ❌

**📝 代码示例**
```javascript

  yield Promise.resolve(1);
  yield Promise.resolve(2);
  yield Promise.resolve(3);
```
