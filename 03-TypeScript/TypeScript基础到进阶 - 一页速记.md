# TypeScript基础到进阶 - 一页速记

## 必背主线

- TypeScript 核心价值是静态类型约束、编辑器提示和重构安全
- 基础类型要掌握 union、intersection、literal、tuple、enum/const enum 的取舍
- 类型收窄是实践高频：typeof、in、instanceof、判别联合、自定义类型守卫
- 泛型是复用核心：函数、组件、工具类型、约束、默认类型参数
- 高级类型关注 mapped type、conditional type、infer、模板字符串类型
