# 前端知识库

个人前端学习与实践知识库，覆盖 HTML/CSS、JavaScript、TypeScript、React、Vue、Node.js、网络与浏览器、工程化、算法和面试准备。

## 开始阅读

- [知识库总览](./知识库总览.md)：按知识层级浏览全部模块。
- [前端学习路径指南](./14-前端学习路径指南.md)：按阶段安排学习顺序。
- [复习清单](./复习清单.md)：面向面试和阶段复盘快速查漏补缺。

各一级目录使用 `00-🌟索引.md` 作为中文主索引，`README.md` 仅作为 GitHub 兼容入口。

## 仓库特点

- 主干专题与课程笔记分开管理，避免学习材料和体系化知识混排。
- 同一重点主题提供完整指南、一页速记、标准答案索引和深挖专题索引。
- 同时兼容 GitHub Markdown 与 Obsidian，新增导航优先使用相对路径链接。
- 内置链接巡检和低信息量笔记扫描，持续发现失效入口与待整理内容。

## 本地维护

```bash
npm install
npm test               # 检查确定失效的相对链接
npm run audit:links    # 严格检查，包括尚未落地的导航双链
npm run audit:thin     # 扫描低信息量笔记候选
npm run check:format   # 检查 Markdown 与配置文件格式
```

治理原则与当前待办见[知识库整理规划](./99-其他/知识库整理规划.md)。
